## SNSリンクの設定方法

SNSリンクは以下の2箇所に設定する必要があります：

1. ヘッダー部分（`index.html`の`header`セクション内）
2. フッター部分（`index.html`の`footer`セクション内）

各SNSアイコンのリンクを設定するには、`index.html`内の以下の部分を編集してください：

```html
<!-- Instagram -->
<a href="YOUR_INSTAGRAM_URL" class="social-icon"><i class="fab fa-instagram"></i></a>

<!-- X (Twitter) -->
<a href="YOUR_X_URL" class="social-icon"><i class="fab fa-x-twitter"></i></a>
```

`YOUR_INSTAGRAM_URL`と`YOUR_X_URL`を実際のSNSアカウントのURLに置き換えてください。
